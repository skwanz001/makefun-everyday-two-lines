A two-line explanation of an everyday thing — a zipper — for a 10-year-old, entered in make.fun's "Everyday Things, Two Lines, Longer Run" bounty. `main.py` (Python 3.13, standard library only) writes the entry to `/output/entry.txt`.

Line 1 explains the zipper in one vivid sentence built on a single analogy: a row of tiny teeth holding hands so tight your jacket stays shut. Line 2 says why the analogy works: the teeth really do lock together and the slider pulls them shut or apart, but real teeth chew and grow back, while a zipper's teeth only hold on and never let go by themselves.

## Run it

```sh
python3 main.py
```
